# SQL Exercise  – Data Analysis

This exercise focuses on analyzing customer orders using SQL Server.

It covers data aggregation, grouping, and date analysis to calculate the number of orders per customer, total orders, and the earliest and latest order dates.

The exercise uses aggregate functions such as `COUNT()`, `SUM()`, `MAX()`, and `MIN()`, along with `GROUP BY`, Common Table Expressions (CTEs), Window Functions, and `CROSS JOIN`.

**Database:** sepidar01  
**Table:** sls.invoice  
**Tool:** Microsoft SQL Server (SSMS)
